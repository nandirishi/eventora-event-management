# EVENTORA – Event Management Website

**Discover Events. Create Memories.**

## About the Project

EVENTORA is a responsive event management website developed using HTML, CSS and JavaScript. The main purpose of this project is to provide users with a simple platform where they can explore upcoming events, search for events based on their interests and register for the activities they want to attend.

The website includes different event categories such as Music, Technology, Workshops, Culture and Sports.

## Features

- **Homepage:** A landing page introducing the EVENTORA platform.
- **Upcoming Events:** Displays event information, including names, dates, venues, images and descriptions.
- **Search Functionality:** Allows users to search for events.
- **Category Filters:** Helps users find events based on their preferred category.
- **Sorting:** Events can be sorted by date or name.
- **Event Registration:** Users can enter their name, email address and phone number to register.
- **Form Validation:** JavaScript checks the registration details before submission.
- **Registration Confirmation:** Displays a confirmation message after successful registration.
- **Login and Sign Up Interface:** Provides an account interface for users.
- **My Registrations:** Intended to display events associated with a user's account.
- **Dark and Light Mode:** Allows users to switch between website themes.
- **Local Storage:** Used to retain selected website preferences and demonstration data.

## How to Run the Project

1. Download or clone the project repository.
2. Open the EVENTORA folder.
3. Open `index.html` in a web browser.
4. Explore the available events and website features.

No additional software installation is required to run the basic website.

## Event Categories

## Data Storage

The project uses browser Local Storage for demonstration purposes. Registration details, account demonstration data and theme preferences can be retained in the browser.

The project does not currently use a server-side database or production authentication system.
